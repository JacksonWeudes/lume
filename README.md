# Lume

Landing page moderna e totalmente responsiva desenvolvida com tecnologias web fundamentais.

## Tecnologias

- HTML5  
- CSS3  
- JavaScript  

## Funcionalidades

- Layout totalmente responsivo
- Menu hambúrguer para dispositivos móveis
- Cards animados e adaptáveis
- Slider de comentários de clientes
- Interface limpa e intuitiva

## Responsividade

A página foi desenvolvida para funcionar corretamente em diferentes dispositivos:

- Desktop
- Tablet
- Mobile

## Objetivo

Este projeto foi criado com fins educacionais, para praticar:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Interatividade utilizando JavaScript
